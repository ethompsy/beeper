Recommended Hybrid Approach

Primary: Direction 1 (Narrative Flow) as the investigation detail base — the streaming timeline is Beeper's signature UX and the strongest trust-building mechanism.

Incorporate from D6: The confidence ring summary card at the top for instant assessment. Expandable sections for evidence depth (progressive disclosure).

Incorporate from D5: Optional split-pane mode (toggle) for users who want raw data alongside the narrative. Sam scrolls the timeline; Alex splits the view.

Incorporate from D3: The approve button with inline context — always visible, always carrying confidence + sandbox status.

Navigation: Direction 1/6 sidebar with Incident Mode / Learning Mode grouping + Cmd+K palette.
